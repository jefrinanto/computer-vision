# computer-vision
This project demonstrates image classification using the VGG16 Convolutional Neural Network (CNN) with pre-trained ImageNet weights. The program takes an image from a URL, downloads and resizes it to 224×224 pixels, converts it into a NumPy array, and preprocesses it according to the VGG16 input requirements. The processed image is then passed to the VGG16 model for prediction. Finally, the program displays the input image and identifies the top three predicted classes along with their confidence scores. This project demonstrates the basic implementation of Transfer Learning and Image Classification using TensorFlow and Keras.
